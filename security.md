## Intended Users
This repository is mainly intended for myself, my professor, and other students in the class. 
It contains code and assignments completed as part of my coursework.

## Security Risk Assessment
I believe the security risk for this repository is relatively low
because it mainly contains academic assignments and code that
does not involve sensitive personal information. However, if
someone gained unauthorized access, they could potentially
modify or misuse the code.

## Security Measures
Since this repository is mainly used for coursework and does
not contain sensitive information, I do not think additional
security measures such as CODEOWNERS or pull request rules
are necessary at this time. I will make sure not to upload
passwords, API keys, or any personal information to the
repository.
